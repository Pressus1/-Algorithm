# Практическое занятие 8

В каталоге находятся три независимые программы на C++17.

## Задача 1 Быстрое возведение в степень

Файл `task1_fast_power.cpp` содержит функцию бинарного возведения в степень. Вводятся целое основание и неотрицательная целая степень через пробел. Результат хранится в собственной десятичной структуре большого целого числа, поэтому не ограничен диапазоном `long long`. Количество умножений — `O(log n)`.

```powershell
g++ -std=c++17 -O2 task1_fast_power.cpp -o task1_fast_power.exe
"10 12" | .\task1_fast_power.exe
```

Ожидаемый результат: `1000000000000`.

## Задача 2 Рекурсивный НОД

Файл `task2_recursive_gcd.cpp` реализует рекурсивный алгоритм Евклида. Вводятся два натуральных числа `a` и `b`.

```powershell
g++ -std=c++17 -O2 task2_recursive_gcd.cpp -o task2_recursive_gcd.exe
"9 12" | .\task2_recursive_gcd.exe
```

Ожидаемый результат: `3`.

## Задача 3 Ингредиенты и три салфетки

Файл `task3_hanoi.cpp` рекурсивно переносит `n` ингредиентов с салфетки 1 на салфетку 3. Ингредиент 1 — самый маленький, ингредиент `n` — самый большой.

```powershell
g++ -std=c++17 -O2 task3_hanoi.cpp -o task3_hanoi.exe
"2" | .\task3_hanoi.exe
```

Ожидаемый результат:

```text
Ingredient 1 move from 1 to 2
Ingredient 2 move from 1 to 3
Ingredient 1 move from 2 to 3
```

## Проверенные случаи

- степень: `10 12`, `2 0`, `-2 5`, `2 100`;
- НОД: `9 12`, `1000000000 999999999`, `42 42`;
- переносы: `n = 1`, `n = 2`, `n = 3`; для `n = 3` получено ровно `2^3 - 1 = 7` строк.
