# Практическое занятие 11

## Задача 1

Файл `task1_max_path.cpp` читает `N M`, затем матрицу `N x M`. Динамическое программирование хранит максимальную сумму для каждой клетки и предка оптимального маршрута. В соответствии с требуемым форматом выводятся только координаты пути от `(0, 0)` до `(N - 1, M - 1)`. При равенстве вариантов выбирается переход сверху, поэтому результат воспроизводим.

Сложность: `O(N*M)` по времени и `O(N*M)` по памяти.

## Задача 2

Файл `task2_pastries.cpp` читает `N D`, затем `N` калорийностей. Пирожки можно распределять произвольно, поэтому после сортировки существует оптимальное разбиение на непрерывные группы. Для заданной границы `X` жадный проход строит минимально возможное число групп с размахом не более `X`; двоичный поиск находит минимальный допустимый `X`. Если получилось меньше `D` групп, любую группу можно дробить до ровно `D` непустых групп без увеличения размаха.

Эквивалентная учебная DP-рекуррентность для отсортированного массива: `dp[d][i] = min_j max(dp[d-1][j], a[i-1]-a[j])`. Программа использует более быструю монотонную проверку допустимости вместо прямого `O(D*N^2)` перебора.

Сложность: `O(N log N + N log R)`, где `R = max(a)-min(a)`; память `O(N)`.

## Задача 3 и неоднозначность условия

Файл `task3_bouquet.cpp` следует только данным из методички: растения названы различными, а на входе присутствует лишь один массив стоимостей без идентификаторов видов. Поэтому каждое растение встречается один раз, ограничение `L >= 1` автоматически выполнено, и ответ равен сумме `K` наибольших стоимостей. Добавлять скрытый массив типов программа не пытается.

Сложность: `O(N log N)` по времени и `O(N)` по памяти.

## Сборка

```powershell
g++ -std=c++17 -O2 -Wall -Wextra -pedantic task1_max_path.cpp -o task1.exe
g++ -std=c++17 -O2 -Wall -Wextra -pedantic task2_pastries.cpp -o task2.exe
g++ -std=c++17 -O2 -Wall -Wextra -pedantic task3_bouquet.cpp -o task3.exe
```

## Проверка

Все три файла собраны GCC 15 в режиме `-std=c++17 -O2 -Wall -Wextra -pedantic` без предупреждений.

Для матрицы из методички внутренняя максимальная сумма равна `38`, а программа вывела маршрут:

```text
0 0
1 0
1 1
2 1
2 2
2 3
```

Задача 2 для `1 2 10 11 20 21`, распределяемых на 3 дня, вывела `1`; для одного дня на наборе `8 1 10 4` — `9`; для четырёх дней — `0`. Дополнительно результат задачи 1 проверен на 200 случайных матрицах, а результат задачи 2 — на 300 случайных наборах сравнением с полным перебором всех разбиений.

Задача 3 для стоимостей `10 5 9 1 7` и `K=3` вывела `26`; для отрицательных стоимостей `-5 -2 -9 -1` и `K=2` — `-3`.
