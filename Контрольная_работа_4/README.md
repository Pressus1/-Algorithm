# Контрольная работа 4 Вариант 4

В методичке сказано, что студенту назначаются три номера, а совпадающие номера последовательно увеличиваются до получения уникальной тройки. Отдельной таблицы персональных троек в документе нет. Поэтому принята явно зафиксированная интерпретация: для варианта 4 исходная тройка `4 4 4` по правилу устранения повторов преобразуется в `4 5 6`.

Выполненные задачи:

1. `task4_min_coins.cpp` находит минимальное количество монет для заданной суммы при неограниченном числе монет каждого номинала. Формат ввода: `n amount`, затем `n` положительных номиналов. Если сумму набрать нельзя, выводится `-1`.
2. `task5_unique_paths.cpp` считает число путей из левого верхнего в правый нижний угол сетки `m × n` при движении только вправо и вниз. Используется целое произвольной точности.
3. `task6_max_subarray.cpp` находит максимальную сумму непустого непрерывного подмассива алгоритмом Кадане.

Сборка каждого решения:

```text
g++ -std=c++17 -Wall -Wextra -Werror -pedantic task4_min_coins.cpp -o task4
g++ -std=c++17 -Wall -Wextra -Werror -pedantic task5_unique_paths.cpp -o task5
g++ -std=c++17 -Wall -Wextra -Werror -pedantic task6_max_subarray.cpp -o task6
```

Примеры:

```text
task4 ввод: 3 11 / 1 5 7
task4 вывод: 3

task5 ввод: 3 4
task5 вывод: 10

task6 ввод: 9 / -2 1 -3 4 -1 2 1 -5 4
task6 вывод: 6
```

Автоматическая проверка запускается файлом `run_tests.ps1`.
