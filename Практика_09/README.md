# Практическое занятие 9

В каталоге находятся три независимые программы на C++17. Каждая использует файловый ввод и вывод и должна запускаться из каталога, в котором лежат её входные файлы.

## Задача 1 Удаление букв

`task1_remove_agreement_letters.cpp` читает `input.txt` и записывает `output.txt`, удаляя все английские буквы, встречающиеся во фразе `user agreement`, без учёта регистра. Пробел из фразы не считается удаляемым символом.

```powershell
g++ -std=c++17 -O2 task1_remove_agreement_letters.cpp -o task1.exe
.\task1.exe
```

Для `useragreement45kkl` получается `45kkl`.

## Задача 2 Поиск подстроки

`task2_substring.cpp` читает строку `X` из `input1.txt`, строку `Y` из `input2.txt` и записывает `yes` или `no` в `output.txt`.

В методичке есть противоречие: основная формулировка требует проверить, является ли `Y` подстрокой `X`, а последняя фраза переставляет строки местами. Реализация следует основной формулировке: ищет `Y` внутри `X`.

```powershell
g++ -std=c++17 -O2 task2_substring.cpp -o task2.exe
.\task2.exe
```

## Задача 3 Замена десятичных чисел двоичными

`task3_numbers_to_binary.cpp` читает первую строку `input.txt`. Каждая максимальная последовательность цифр считается одним десятичным числом и заменяется его двоичной записью; остальные символы сохраняются. Результат записывается в `output.txt`. Деление десятичной строки на два позволяет корректно обрабатывать число любой длины в пределах ограничения строки без переполнения стандартных целых типов.

```powershell
g++ -std=c++17 -O2 task3_numbers_to_binary.cpp -o task3.exe
.\task3.exe
```

Пример из методички преобразуется в:

```text
110^&1010100110JKjdkdl;?.,lk1101101111Pk1kdfl1001011100111
```

## Проверенные случаи

- удаление букв: пример методички и смешанный регистр `User AGREEMENT + xyz`;
- подстрока: найденная подстрока, отсутствующая подстрока и совпадение всей строки;
- числа: пример методички, число `0`, несколько соседних числовых групп и большое число, выходящее за диапазон 64 бит.
