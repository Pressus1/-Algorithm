# Практическое занятие 14

## Задача 1

`task1_brackets.cpp` считывает сообщение целиком, игнорирует обычные символы и проверяет правильность трёх типов скобок: `()`, `[]`, `{}`. Вывод — `yes` или `no`. Стек работает за `O(n)` времени и использует до `O(n)` памяти.

## Задача 2

`task2_unique_words.cpp` обрабатывает текст в UTF-8, приводит латинские и русские буквы к нижнему регистру, удаляет пунктуацию и выводит уникальные слова в порядке первого появления. Дефис внутри слова сохраняется и нормализуется в `-`, поэтому пример `всё-таки` остаётся одним словом. Для воспроизводимости программа не зависит от системной локали Windows.

Сложность: `O(n log u)`, где `u` — число уникальных слов; память `O(n)`.

## Задача 3

`task3_min_stack.cpp` содержит собственный класс `MinStack`. Каждая позиция хранит значение и минимум на префиксе, поэтому `push`, `pop`, `empty` и `minimum` работают за `O(1)`. Демонстрационная оболочка читает число команд, затем команды `push X`, `pop`, `empty`, `min`. `pop` печатает извлечённый элемент, а операции над пустым стеком печатают `error`.

## Сборка

```powershell
g++ -std=c++17 -O2 -Wall -Wextra -pedantic task1_brackets.cpp -o task1.exe
g++ -std=c++17 -O2 -Wall -Wextra -pedantic task2_unique_words.cpp -o task2.exe
g++ -std=c++17 -O2 -Wall -Wextra -pedantic task3_min_stack.cpp -o task3.exe
```

## Проверка

Все три файла собраны GCC 15 в режиме `-std=c++17 -O2 -Wall -Wextra -pedantic` без предупреждений.

- Задача 1: пример `В МИРЭА и без меня?))` дал `no`, строка `abc ([{}])` — `yes`, строка `([)]` — `no`, текст без скобок — `yes`.
- Задача 2: пример из методички с повтором `КОГДА` вывел 16 уникальных слов в нужном порядке; повтор не появился второй раз, а `всё-таки` сохранилось одним словом.
- Задача 3: проверены извлечение, минимум после нескольких операций и ошибки пустого стека. Дополнительно 200 случайных последовательностей команд сравнены с эталонной моделью; расхождений нет.
